# Courses

A collection of courses, tutorials, and practice exercises I've worked through
while learning web development, organized by technology. This is where I keep
the raw practice — for more complete, standalone projects, see
[`jscamp-bootcamp`](https://github.com/stalindlcruz/jscamp-bootcamp) and
[`early-projects`](https://github.com/stalindlcruz/early-projects).

## What's inside

| Folder                        | Covers                                                                                                              | Notes                                                                                                                                                        |
| ----------------------------- | ------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| [`HTML/`](./HTML)             | Semantic HTML5, forms, tables, accessibility, and practice pages styled after real sites (DiarioLibre, PlayStation) | Includes both a structured course (`curso-html5`) and standalone practice pages                                                                              |
| [`CSS/`](./CSS)               | Selectors, pseudo-classes, Flexbox, Grid, responsive design, plus Bootstrap and Tailwind practice                   | The richest folder for visual practice — separates fundamentals from framework-specific work                                                                 |
| [`JavaScript/`](./JavaScript) | Core JS (types, functions, arrays, objects, classes, DOM, events, fetch, async/await) through three levels of depth | `javascript/` is a structured course, `learn-javascript/` is early practice, `ultimate-js/` includes a more complete project with fetch + forms + validation |
| [`TypeScript/`](./TypeScript) | OOP with TypeScript, plus a small Express + REST API project                                                        | `typescript-sin-fronteras/` goes beyond theory into a working backend                                                                                        |
| [`Astro/`](./Astro)           | A minimal Astro starter project with Tailwind and TypeScript                                                        | Closer to a mini-project than a course                                                                                                                       |
| [`Python/`](./Python)         | Python fundamentals, plus small apps built with Flask (web) and Tkinter (desktop)                                   | `python-sin-fronteras/` is the most complete section here                                                                                                    |

## Why this repo exists

I prefer keeping these in one place instead of as 18 separate repos — it's
easier to see the full learning path at a glance, and easier to keep organized
going forward as I add new courses.
